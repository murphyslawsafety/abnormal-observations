## 0. Correction in direction

The previous Powerball line repeatedly approached the problem from the rendered physical layer:
- labels;
- object recurrence;
- ball sets;
- machines;
- pretest frequencies;
- hardware-conditioned statistics;
- and finally proposed mass/wear/calibration measurements.

Those variables may matter to an ordinary mechanical-bias investigation, but they are not the primary target of the deeper-code program.

This experiment therefore changes the question.

It does **not** ask:

> Which measured nuisance variables make a particular ball more likely?

It asks:

> What low-complexity transformation grammar, quotient structure, composition law, invariant structure, and observer-dependent state partition could generate the observed pretest→draw records as a compiled readout?

Numbers, ball sets, machines, weather, weight, wear, and other implementation details are treated as possible **realization-layer metadata**, not as the discovery substrate.

The exact draw remains a downstream checksum.

## 1. Cross-project lessons imported as architecture

No sibling project is counted as evidence that Powerball is predictable. The import is methodological.

### Reality-Code
- recover the generator / operation grammar before fitting the final observable;
- topology/order can transfer better than amplitude or metric transient;
- require prediction **and** identifiability;
- two realizations that render the same output must remain explicitly equivalent rather than being falsely identified;
- source-domain structure has evidential value only when it reduces uncertainty unavailable from target-only calibration;
- under conjugacy, composition and commutator structure can transfer even when local coordinates differ.

### LIFE-CODE
- persistent primitives need not imply persistent exact higher-order compositions;
- flat exact dictionaries and naive spatial/order relations can fail while hierarchy remains the correct level of attack;
- search across levels: primitive → motif → module → grammar;
- a quotient interpretation must survive context, prevalence, and held-out transfer controls.

### ENERGY-CODE / Gravity-Code
- ordered operations can matter even when the set of operations is unchanged;
- noncommuting transformations can carry information in commutators / loop orientation / holonomy;
- the relevant object may be a path in operation space rather than an instantaneous scalar state.

### Observer-Code
- the observed state may be a quotient of a richer state;
- infer hidden equivalence partitions from behavior, not from supplied labels;
- an apparent random output may be many-to-one under the observation map;
- the correct state is the equivalence class of histories that are indistinguishable under admissible future probes.

### Unified-Code
- direct closure, closure requiring a hidden/measured ledger, no supported closure, and insufficient-identifiability are distinct outcomes;
- a high-fit pseudo-invariant is rejected when identifiability / singular-gap gates fail;
- closure must transfer under one frozen abstract signature rather than being rederived separately in each case.

### Resonance-Code
- source-derived algebraic relations can predict withheld compositions when target-only calibration is insufficient;
- composition relations are often more informative than isolated values;
- the next meaningful layer may contain multiple hidden, possibly noncommuting relations rather than one scalar resonance.

## 2. Core ontology

Treat one completed Powerball date as a **word acted on by an observation/compiler map**.

Let:

- `X` = hidden substrate state space;
- `G` = unknown transformation grammar;
- `g_t in G` = latent operation associated with one event transition;
- `x_{t+1}=g_t x_t` = latent evolution;
- `Q:X→Z` = observer/quotient map into an observable relational state;
- `C:Z→Y` = compiler/readout map;
- `Y` = rendered official draw labels.

We do **not** assume any of these maps are deterministic in the microscopic sense. A probabilistic kernel is allowed.

The scientific target is the equivalence class:

`[G,Q,C]`

up to representation changes / conjugacy that preserve observable predictions.

## 3. What is discarded at discovery time

The first grammar-discovery pass must not use:

- numerical magnitude of printed labels;
- ball weight;
- weather;
- jackpot;
- machine age;
- wear measurements;
- human ticket behavior;
- prize outcome;
- physical geographic metadata.

Ball labels are used only to establish equality/identity relations **within the historical record**, then canonicalized away.

Machine and set IDs are withheld from grammar discovery and reserved for **post-discovery realization tests**:
- does the same abstract grammar appear under multiple implementations?
- does a candidate grammar collapse to a particular machine/set realization?

If the abstract grammar requires hardware identity merely to exist, that is evidence for an implementation-specific model, not substrate-level transfer.

## 4. Canonical anonymous event object

Each historical completed block consists of:

`P1 → P2 → P3 → P4 → D`

where each white row contains five identities and each PB row one identity.

Construct an anonymous canonical structure in which original labels are replaced by first-occurrence symbols.

Example only:

`[17,4,61,9,33] → [4,52,17,8,12]`

becomes a relation like:

`[a,b,c,d,e] → [b,f,a,g,h]`.

The canonical form retains:
- equality / recurrence;
- extraction position;
- order;
- co-occurrence;
- disappearance;
- reappearance;
- novel-object introduction;
- relation between white and PB channels only if independently justified.

It destroys:
- printed numerical magnitude;
- arbitrary label names.

Two blocks that differ only by a bijective relabeling are therefore the same observable relational object.

## 5. Primitive transformation alphabet

For every adjacent pair of rows, construct a canonical partial transformation operator.

For white rows, the primitive operator records:
- which prior identities survive;
- their old→new extraction-position map;
- which positions are occupied by novel identities;
- equality relations among any identities that appeared earlier in the same block.

Represent this as a canonical partial permutation / incidence operator:

`T_12, T_23, T_34, T_4D`.

The PB channel has its own recurrence/novelty operator.

No primitive class is named by machine, set, date, or label.

The initial alphabet is the set of distinct canonical operator signatures observed in the training history.

## 6. Quotient / hidden-state inference

Raw primitive signatures may still be an overcomplete rendering.

Infer a coarser equivalence relation:

`u ~ v`

when operation histories ending in u and v are indistinguishable under a frozen family of future composition probes within statistical tolerance.

This is a behavioral / predictive bisimulation criterion, not a hand-labelled partition.

Candidate quotient levels:

- Q0: exact canonical primitive signature;
- Q1: same support topology;
- Q2: same orbit/partition action on identity classes;
- Q3: same action on the independently derived invariant algebra.

The experiment must select the **coarsest** quotient that preserves held-out composition behavior within the frozen error threshold.

This is the Observer-Code-style hidden partition problem.

## 7. Grammar before outcome

The primary prediction target is **not the next five numbers**.

Given only:

`T_12, T_23, T_34`

and past history, predict the equivalence class of:

`T_4D`.

Then predict higher-level composition objects such as:

`W = T_4D T_34 T_23 T_12`.

Only after a grammar class survives do we compile its predicted `T_4D` class into a probability distribution over exact rendered draws compatible with that class.

This keeps the official numbers in their intended role: checksum.

## 8. Hierarchical grammar levels

Exactly four grammar scales are tested.

### H1 — primitive
Distribution / algebra of individual canonical operators.

### H2 — composition
Ordered pairs and triples:
- `T_23 T_12`;
- `T_34 T_23`;
- `T_34 T_23 T_12`.

### H3 — module
Equivalence classes of complete pretest words:

`T_34 T_23 T_12`.

The question is whether particular modules constrain the admissible fourth operator `T_4D`.

### H4 — meta-grammar
Relations among modules across dates:
- which modules compose / recur;
- which modules are equivalent under conjugacy;
- which operator relations are stable while local realization changes.

No additional hierarchy level may be added after scoring under this experiment ID.

## 9. Order / noncommutativity channel

For any pair of composable operator representatives A,B, compute order-sensitive diagnostics where defined:

- `AB`;
- `BA`;
- support difference between AB and BA;
- commutator surrogate `AB-BA` in the canonical matrix representation;
- rank / singular spectrum of the commutator;
- conjugacy-invariant spectrum where meaningful.

For three-step words, compare:
- observed order `T34 T23 T12`;
- reversed order;
- deterministic order permutations.

The primary order question:

> Does the actual operation word constrain the held-out completion more strongly than the same primitives under order-destroyed controls?

A positive result must survive matched nulls. Known noncommutative physics elsewhere does not count as evidence here.

## 10. Independent invariant channel

Do not derive the grammar only from observed transitions.

Independently construct invariants / stabilizers from completed historical blocks.

Candidate invariant family is fixed before execution and includes only anonymous relational quantities:
- orbit partition of repeated identities;
- support topology;
- ranks of canonical incidence maps;
- cycle structure of surviving-identity partial permutations;
- singular spectra;
- graph Laplacian spectra;
- composition ranks;
- commutator ranks/spectra;
- dimensions of approximate nullspaces;
- multiplicities of equivalence-class actions.

From the operation channel derive:
`I_O = invariants implied by learned grammar`.

From the invariant channel independently reconstruct the admissible operation algebra:
`G_I = operations compatible with learned invariants`.

Primary closure checksum:

`G_I ≈ G_O`
and
`I_O ≈ I_data`.

A high predictive score without dual reconstruction cannot advance.

## 11. Hidden-ledger branch

Unified-Code showed that some systems close only after introducing an explicit ledger/state variable.

Therefore the grammar classifier has four allowed outcomes:

### A — DIRECT_CLOSURE
Low-complexity operation grammar and invariant closure agree without an extra state.

### B — LEDGER_CLOSURE
Closure requires one minimal latent ledger variable inferred prospectively from histories.

The ledger is allowed only if:
- it is lower description length than the unexplained residual;
- it transfers without refit;
- its update rule is frozen before held-out evaluation;
- it is not a disguised date/machine/set label.

### C — NO_LOW_COMPLEXITY_CLOSURE
No candidate grammar survives MDL / held-out / invariant closure.

### D — UNIDENTIFIABLE
Multiple incompatible grammars remain observationally equivalent under available probes.

D is a legitimate scientific outcome, not a failure to be patched.

## 12. Nontrivial transfer requirement

A grammar result is evidential only if the source/training grammar reduces uncertainty unavailable from target-only calibration.

Historical dates are partitioned into source and target eras by a deterministic SHA rule frozen before scoring.

For each target era:
- permit limited target calibration sufficient to map local symbols into the abstract grammar;
- deliberately withhold some composition words;
- require source-derived grammar to predict those withheld words;
- compare against a capacity-matched target-only model receiving exactly the same target calibration.

If target-only calibration already determines the held-out word, the case is **NONDISCRIMINATING**, not a success.

This implements the project's cross-domain transfer nontriviality rule.

## 13. Reality / implementation separation

Only after a grammar survives abstract tests do we expose:
- machine IDs;
- ball-set IDs;
- dates / eras;
- any future physical measurements.

Then ask whether the same grammar:
- appears across multiple physical implementations;
- is conjugate across implementations;
- or collapses to one apparatus realization.

This is where weights, wear, machine identity, environment, etc. belong: **interpretation of an already-recovered grammar**, not initial discovery features.

## 14. Historical execution structure

### Stage 0 — canonicalization qualification
Must prove:
- exact invariance under arbitrary within-set relabeling;
- no numeric-label leakage;
- canonical operator serialization stable;
- fair/synthetic controls render correctly.

### Stage 1 — grammar discovery
Use a deterministic development subset to:
- enumerate the primitive operator alphabet;
- compute quotient candidates Q0–Q3;
- construct H1–H4 grammar candidates;
- identify DIRECT / LEDGER / NO_CLOSURE / UNIDENTIFIABLE classes under MDL.

No official exact-number scoring is primary here.

### Stage 2 — dual reconstruction
Require operation-derived and invariant-derived structures to close on the development subset and on a validation subset.

### Stage 3 — nontrivial historical transfer
Frozen grammar predicts held-out operator compositions / T4D classes in target eras where target-only calibration is intentionally insufficient.

### Stage 4 — rolling-origin checksum
Only surviving grammar is compiled into exact draw probabilities and tested in strict historical walk-forward.

### Stage 5 — matched full-pipeline nulls
Only if Stage 4 is positive.

### Stage 6 — live readiness
Only if the exact unchanged grammar survives all prior stages.

## 15. Nulls that attack the grammar rather than the noise

Required null/control families:

### N1 — identity relabeling
Arbitrary bijective relabeling must leave grammar results invariant.

### N2 — order destruction
Permute P1..P4 while preserving each row's internal identity relations.

### N3 — word recombination
Recombine real primitive operators into synthetic words preserving primitive frequencies but destroying composition grammar.

### N4 — quotient-preserving decoy
Generate histories that preserve selected low-level quotient statistics but scramble higher-order composition.

### N5 — invariant-preserving wrong grammar
Construct decoys matching the frozen invariant spectrum as closely as possible while changing admissible composition relations.

### N6 — target-only sufficiency control
Test whether held-out compositions were already determined by target calibration.

### N7 — fair outcome compiler
Keep learned pretest-word statistics but attach fair random rendered draw outcomes.

The entire search/selection pipeline must run under applicable nulls.

## 16. Advancement gates

A grammar may advance only if all are true:

1. description length beats the no-grammar baseline after search penalty;
2. held-out T4D/operator-class prediction beats frequency baseline;
3. operation-derived and invariant-derived grammars agree under the frozen closure metric;
4. quotient class is stable under bootstrap / era perturbation;
5. source grammar improves withheld-composition prediction beyond capacity-matched target-only calibration;
6. actual ordering beats order-destroyed controls;
7. result is invariant to label renaming;
8. identifiability is sufficient, or outcome is explicitly D/UNIDENTIFIABLE;
9. the grammar transfers to at least two implementation/era partitions before rendered-number prediction is attempted.

## 17. Exact-number boundary

No exact ticket is generated during grammar discovery.

An exact-number/ticket mapping is permitted only after a grammar passes Stages 0–5.

At that point, a separately frozen compiler maps:
- current observable pretest word;
- inferred quotient state;
- learned grammar;
- any legitimate latent ledger

into a normalized distribution over compatible rendered draw outputs.

A live experiment receives a new experiment ID.

## 18. Relation to prior Powerball experiments

RCX-PB-GC-0001 through 0004 remain legitimate preserved negatives under their own representations.

They are **not** reinterpreted as evidence for this grammar model.

Their main methodological lesson is that:
- label/statistical patterns;
- simple physical recurrence;
- global low-rank closure;
- and public-record discriminability witnesses

did not earn prediction.

This new experiment asks a different question at a different representation level.

## 20. Claim ceiling

A PASS would mean:

> a low-complexity anonymous transformation grammar was recovered from the lottery event record, survived independent operation/invariant reconstruction, and transferred nontrivially to held-out compositions better than controls.

It would **not yet** mean:
- the lottery is predictably beatable;
- the grammar is universal to reality;
- microscopic determinism has been demonstrated;
- a simulation/substrate ontology has been proven.

The rendered-number/live-prediction layer remains a later checksum.
