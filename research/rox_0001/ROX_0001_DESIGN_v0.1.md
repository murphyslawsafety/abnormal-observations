## 0. Direction correction

The Powerball branch has repeatedly tried to infer a grammar from Powerball itself.

That is still too target-specific for the cross-project hypothesis.

If the candidate architecture is genuinely deeper than any one implementation, the strongest test is the reverse:

1. infer/freeze the abstract grammar from the already-developed independent project family;
2. leave one domain out;
3. require the source grammar to recover a relation in the held-out domain that target-only calibration cannot already determine;
4. only after that architecture survives cross-domain transfer, use Powerball as a blind target/checksum.

Powerball therefore stops being a source of theory and becomes a hostile target.

## 1. Candidate universal signature

Each scientific domain is represented by an abstract signature:

`Sigma = (Q,T,C,I,O,L,R,M)`

where:

- `Q` — observer quotient / equivalence classes: what distinctions are visible;
- `T` — admissible transformations/operators;
- `C` — composition relations among transformations;
- `I` — invariants/stabilizers/closure constraints;
- `O` — order sensitivity / noncommutativity / loop orientation;
- `L` — ledger or hidden closure state when direct closure fails;
- `R` — retained record/history dependence;
- `M` — second-order observer/self-model dependence.

Fields can be:
- supported;
- unsupported;
- unidentifiable;
- not tested.

No missing field is silently inferred as present.

## 3. Meta-grammar target

The meta-compiler seeks a minimal cross-domain grammar `Gamma` that predicts admissible relations among the signature fields.

Examples of relation forms that may be tested:

- quotient-preserving transformation:
  `q o T = Phi_T o q`;

- dual closure:
  operations imply invariants and invariants constrain the same operation algebra;

- composition transfer:
  source-derived relations predict withheld target compositions;

- order relation:
  `AB != BA` or loop orientation changes the allowed/observed result;

- ledger closure:
  direct closure fails but one low-complexity state update closes the system;

- recursive-observer relation:
  a model of the observation/model state changes later observable behavior beyond raw-history control.

The meta-grammar is not required to contain all relation types.

The selected grammar is the lowest-complexity one that survives source-domain controls and leave-one-domain-out transfer.

## 4. Leave-one-domain-out rule

For each eligible domain D:

1. remove D from source fitting;
2. build `Gamma_{-D}` from the remaining domains;
3. expose only a frozen calibration interface from D;
4. deliberately withhold at least one relation in D;
5. predict the withheld relation using `Gamma_{-D}`;
6. compare against a capacity-matched target-only learner given the same calibration.

A transfer is nontrivial only when:

`uncertainty(target | source grammar + calibration) < uncertainty(target | calibration only)`.

If target-only calibration already determines the result, classify it NONDISCRIMINATING.

## 5. Required controls

The pipeline must reject:

- semantic-label transfer: project/domain names are permuted;
- representation relabeling: coordinates/names change but structure is preserved;
- wrong-grammar libraries matched in parameter count;
- relation-shuffled domains preserving field marginals;
- pseudo-invariants that fit but fail identifiability;
- target-only sufficiency;
- post-hoc ledger invention;
- source cherry-picking.

The source set and exclusion rules must be frozen before scoring.

## 6. Powerball as a blind target

The target adapter may use pre-draw/pretest structure only to map the target into the frozen abstract signature.

Powerball target questions become:

1. what is the observer quotient Q?
2. what transformations T are observable?
3. what compositions C are defined?
4. which invariants I are forced by the frozen source grammar?
5. does order O matter under the frozen source relation?
6. is an additional record/ledger R required?
7. is the target relation identifiable at all?

The draw is then a held-out compiled checksum.

## 7. Gauge / exact-label boundary

A representation-invariant grammar cannot by itself choose arbitrary Powerball labels.

Let:
- `B` = anonymous quotient state;
- `Y` = concrete labeled state;
- `G = S_69 x S_26` = relabeling symmetry;
- `q:Y->B` = quotient.

To output exact numbers, the target must provide a prospectively identifiable symmetry-breaking compiler:

`s:B -> Y`

or an equivalent connection/transport rule that selects a concrete labeling from the fiber over B.

If the frozen grammar predicts only an orbit/equivalence class and no target-side section is identifiable without draw outcomes, classify the target:

`ABSTRACT_ONLY`.

No exact ticket may be manufactured from an ABSTRACT_ONLY result.

This is the formal reason that "grammar" and "numbers" are separate problems.

## 8. Recursive Observability criterion

ROX-0001 does not assume recursive self-observation merely because Q,T,C,I exist.

Specific ROH recursive support requires a held-out relation involving R or M in which:
- the record/model of prior observation is itself part of the next state update;
- a capacity-matched non-reflexive control fails;
- the relation transfers to an unrelated natural domain.

Without this, the result is structural observability/closure, not "Observation Observing Itself" at the recursive level.
